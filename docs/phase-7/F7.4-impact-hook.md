# F7.4 Optional Git-hook Impact Reports

**Phase**: 7 — ctx-sys Integration
**Priority**: Low
**Dependencies**: F7.1, F6.2

## Goal

Optionally install a `pre-commit` hook that asks ctx-sys "what's affected by this diff?" and surfaces the answer to whichever agent is performing the commit (notably the merge-resolver agent in F6.2).

## Behavior

- `yaao init --ctx-sys-hook` (or `yaao skills install --ctx-sys-hook`) installs `.git/hooks/pre-commit` (managed by yaao; appended to existing hook with delimiters).
- The hook calls `ctx-sys hooks impact-report --diff <staged-diff>` and writes the result to `.yaao/impact-report.json`.
- The merge-resolver agent (F6.2) reads `.yaao/impact-report.json` (if present) and includes it in its prompt context: "These entities and decisions are likely affected by this merge."
- The hook does *not* block commits even if ctx-sys is unavailable — it logs a warning and exits 0.

## Why optional?

- Most users don't want yaao mucking with git hooks.
- Most tasks don't need the impact graph; the agent can `context_query` directly when it cares.
- This is included for completeness because ctx-sys exposes it; we don't push it.

## Removal

`yaao skills install --ctx-sys-hook=remove` strips the managed block. Manual edits between delimiters are preserved.

## Acceptance Criteria

- Hook installs idempotently (re-installing doesn't duplicate the block).
- Hook respects existing pre-commit hooks (appends, doesn't replace).
- Hook exits 0 on ctx-sys unavailability.
- Removal is clean.
