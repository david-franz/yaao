# F7.3 Query Enforcement (`require-query`)

**Phase**: 7 — ctx-sys Integration
**Priority**: Medium
**Dependencies**: F7.1, F7.2

## Goal

When `context.ctx-sys.require-query: true`, fail any task that produced a non-empty diff without ever calling the `context_query` MCP tool. This turns "the agent should query ctx-sys" from a hope into a contract.

## Mechanism

1. The MCP server (running for this yaao run) tags each session with the `runId/taskId` it was spawned for, captured in a `yaao-task` field of the MCP initialization request.
2. ctx-sys logs every tool call with that tag (or a separate audit JSONL the yaao-managed server writes).
3. After a task completes, the lifecycle (F5.2) reads the audit and counts `context_query` calls scoped to this task.
4. If `require-query` and the diff is non-empty and `context_query` calls = 0, the task fails with `YAAO_REQUIRE_QUERY_VIOLATION`.

## System-prompt Directive

Independent of enforcement, every task with ctx-sys enabled gets a prepended system prompt:

```
This project uses ctx-sys for codebase context. BEFORE writing or modifying code,
call the `context_query` MCP tool with a query relevant to the task. Examples:
  - "How is authentication wired up?"
  - "Where is the database schema defined?"
You may call it multiple times. The tool returns curated context from this codebase.
```

The directive is suppressed if the user supplies their own via `task.systemPrompt`.

## Failure Output

```
✘ task 'api' failed: YAAO_REQUIRE_QUERY_VIOLATION
  the task produced a diff (12 files changed) but never called the
  ctx-sys context_query tool. either:
    - rerun with the agent guided by ctx-sys, or
    - set context.ctx-sys.require-query: false on this task or globally.
```

## Per-task Override

```yaml
- id: trivial-readme-edit
  context:
    ctx-sys:
      require-query: false
```

For genuinely trivial tasks (docs typos, one-line bumps) where forcing a query is overkill.

## Acceptance Criteria

- A task that does query ctx-sys completes normally.
- A task that doesn't query but produces no diff completes normally.
- A task that doesn't query and produces a diff fails with `YAAO_REQUIRE_QUERY_VIOLATION`.
- Per-task override works as expected.
- The check is robust to MCP server restart (counts are per session-tag, not per process lifetime).
