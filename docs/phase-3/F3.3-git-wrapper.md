# F3.3 Git Operations Wrapper

**Phase**: 3 — Worktree & Git Engine
**Priority**: Critical
**Dependencies**: F1.5

## Goal

A thin, typed wrapper around `git` invoked via `execa`. All other modules use this; nothing else shells out to git directly. This keeps git error handling in one place and makes the rest of the codebase mockable.

## API Sketch

```typescript
// src/git/git.ts
export interface Git {
  // identity / state
  rootDir(cwd?: string): Promise<string>;
  isRepo(cwd?: string): Promise<boolean>;
  currentBranch(cwd?: string): Promise<string>;
  status(cwd?: string): Promise<GitStatus>;        // porcelain v2 parsed
  hasUncommitted(cwd?: string): Promise<boolean>;

  // refs
  revParse(ref: string, cwd?: string): Promise<string>;  // sha
  branchExists(branch: string, cwd?: string): Promise<boolean>;
  createBranch(branch: string, base: string, cwd?: string): Promise<void>;
  deleteBranch(branch: string, opts?: { force?: boolean }, cwd?: string): Promise<void>;

  // worktrees
  worktreeAdd(path: string, branch: string, cwd?: string): Promise<void>;
  worktreeRemove(path: string, opts?: { force?: boolean }, cwd?: string): Promise<void>;
  worktreeList(cwd?: string): Promise<WorktreeInfo[]>;

  // changes
  merge(branch: string, opts?: { ff?: boolean; noEdit?: boolean; message?: string }, cwd?: string): Promise<MergeResult>;
  mergeAbort(cwd?: string): Promise<void>;
  diff(opts?: DiffOpts, cwd?: string): Promise<string>;
  log(opts?: LogOpts, cwd?: string): Promise<LogEntry[]>;

  // remote
  push(remote: string, branch: string, opts?: { setUpstream?: boolean }, cwd?: string): Promise<void>;
  fetch(remote?: string, refspec?: string, cwd?: string): Promise<void>;
}

export interface MergeResult {
  ok: boolean;
  conflicts: string[];      // files in conflict, empty when ok
  mergeCommit?: string;     // sha if a merge commit was produced
}
```

## Implementation Notes

- All `cwd` parameters default to `process.cwd()`. Callers (worktree manager, merge engine) always pass an explicit cwd.
- `git status --porcelain=v2 --branch` is parsed deterministically; never regex against human-readable git output.
- `merge` returns `{ ok: false, conflicts }` rather than throwing on conflicts. Throws `GitError` only on non-conflict failures (network, missing branch, etc.).
- All commands run with `GIT_TERMINAL_PROMPT=0` and no `-i`/interactive flags.
- `execa` `reject: false` lets us inspect exit codes; we wrap into typed errors.

## Error Types

```typescript
export class GitError extends YaaoError {
  readonly cmd: string[];
  readonly exitCode: number;
  readonly stdout: string;
  readonly stderr: string;
}
```

## Capabilities Probe

`Git.version()` returns the installed git version; `yaao doctor` (F13.1) consumes this to enforce git ≥ 2.40 (worktree improvements).

## Acceptance Criteria

- 100% of git invocations in yaao go through this module (enforced by an ESLint rule banning `execa('git', ...)` outside `src/git/`).
- `merge` reports conflicts as data, not exceptions.
- Status parsing handles renames, untracked files, and submodules without crashing.
- The module exposes a `mockGit()` test helper that records calls and returns scripted responses.
