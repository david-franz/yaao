# F11.1 Ink Rendering Primitives & DAG Renderer

**Phase**: 11 — TUI
**Priority**: High
**Dependencies**: F2.1, F5.2

## Goal

Build the small set of reusable Ink components used by both `yaao view` (static) and `yaao run` (live). The non-trivial one is the DAG renderer — a terminal-friendly layout for the task graph.

## Components

```
src/tui/primitives/
├── status-table.tsx       # task table with sortable columns
├── log-pane.tsx           # scrolling text pane with auto-tail
├── help-footer.tsx        # keybindings + status line
├── dag-graph.tsx          # the DAG renderer
├── focus.ts               # keyboard focus manager
└── theme.ts               # color tokens
```

## DAG Renderer

The renderer takes a `ResolvedPlan` and produces a stream of styled rows for Ink.

### Layout Algorithm

1. **Layer assignment** — longest-path layering (each task placed at `1 + max(layer of deps)`).
2. **Row ordering within a layer** — stable, by topological-then-lexicographic.
3. **Width capping** — if any layer would exceed the terminal width, wrap into multiple visual rows. The graph remains correct; visual edges may cross.
4. **Edge drawing** — Unicode box-drawing chars for direct edges; `╾─╼` for back-references when a layer wraps.

### Render Sketch

```
oauth-feature                                      9 tasks · 3 layers · width 2

  layer 1                    layer 2                       layer 3
  ┌──────────────┐           ┌─────────────────┐          ┌──────────────────┐
  │ scaffold     │──┬───────▶│ api             │──┬──────▶│ integration      │
  │ claude-code  │  │        │ cursor          │  │       │ codex            │
  │ ✔ done       │  │        │ ⠦ running 0:42  │  │       │ ⏸ pending        │
  └──────────────┘  │        └─────────────────┘  │       └──────────────────┘
                    │        ┌─────────────────┐  │
                    └───────▶│ ui              │──┘
                             │ api/anthropic   │
                             │ ⏸ pending       │
                             └─────────────────┘
```

Status uses small icons: `⏸ pending`, `▶ ready`, `⠦ running` (animated spinner), `✔ done`, `✘ failed`, `⊘ skipped`.

## Status Table

Columns: `id`, `status`, `agent`, `branch`, `duration`, `files`, `last`. Sortable by any column (`s` toggles). Always sorts within status groups: running first, then pending, completed, failed.

## Log Pane

Tails the most recent N lines for the selected task. Supports scroll-back with `PgUp`/`PgDn`. ANSI color from agent output is preserved.

## Help Footer

```
[↑↓] select  [enter] log  [s] sort  [r] retry  [c] cancel  [v] graph/table  [q] quit
```

## Theme

Colors are tokenized so we can ship a low-color fallback for tmux/screen. Status colors:
- pending: dim
- ready: cyan
- running: yellow + spinner
- completed: green
- failed: red
- skipped: gray

## Acceptance Criteria

- DAG renders without overlapping edges for plans up to 30 tasks at 4 layers wide.
- Wide plans wrap gracefully; the renderer doesn't crash on 200×40 terminals.
- Spinner runs at ~10 fps without flickering text.
- All components tolerate `process.stderr` not being a TTY (degrades to text mode).
