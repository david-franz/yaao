# F11.3 `yaao run` Live Monitor

**Phase**: 11 — TUI
**Priority**: High
**Dependencies**: F5.4, F11.1

## Goal

The live UI when `yaao run` is in progress. Subscribes to the run bus, updates as tasks transition, lets the user retry/cancel.

## Layout

Default screen split:

```
┌─────────────────────────────────────────────────────┬───────────────────────────────┐
│ Task Table                                          │ Selected Task Log             │
│ id           status   agent       branch   dur  files│ <streaming output>           │
│ scaffold     ✔ done   claude      …/scaff  0:42 14   │                              │
│ api          ⠦ run    cursor      …/api    0:18 7    │                              │
│ ui           ⠦ run    api         …/ui     0:15 0    │                              │
│ integration  ⏸ wait   codex                          │                              │
├─────────────────────────────────────────────────────┴───────────────────────────────┤
│ run a3f1k · plan: my-feature · 1/4 done · max-parallel 4 · ctx-sys ✔                 │
│ [↑↓] select [enter] graph [r] retry [c] cancel [g] graph view [q] quit              │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

## Modes

- **Default** — split view (table + log).
- **Graph** (`g`) — DAG renderer fills the screen; selected task's status is highlighted.
- **Detail** (`enter`) — full-screen task detail (prompt, last 200 lines of output, diff stat).

## Live Updates

- Subscribes to `RunBus` (F5.2) via `asyncIterator()`.
- Status table re-renders on every `task:*` event (debounced to 10 fps to avoid flicker).
- Log pane streams `stdout`/`stderr`/`tool-use` events for the selected task; switching selection changes the stream.

## Keybindings

```
[↑↓ jk]       select task
[enter]       task detail (full-screen)
[g]           graph view
[v]           toggle graph / table when in graph mode
[r]           retry selected failed task (if retries remain)
[c]           cancel selected running task
[shift-c]     cancel run
[/]           filter
[q]           quit (does NOT cancel; run continues in background if --background; otherwise prompts)
```

## Cancellation

- `q` prompts: "Run is in progress. (q)uit and detach, (c)ancel run, (esc) keep watching".
- `shift-c` immediately requests cancellation of the run; the engine handles graceful shutdown (F5.2).

## Detach Mode

Detaching (q → quit) leaves the run processing. The user can re-attach with `yaao status <run-id> --watch` (F11.5).

## Acceptance Criteria

- Updates feel real-time without flicker.
- Switching task selection within ~50ms swaps the log pane content.
- Cancellation actions emit the correct signals to the engine.
- Detach + re-attach round-trips correctly via the journal.
