# F11.5 `yaao status` Command

**Phase**: 11 — TUI
**Priority**: Medium
**Dependencies**: F3.4, F11.3

## Goal

Inspect a finished or in-flight run from a separate terminal. Re-attach to a detached `yaao run`. Print a compact text summary for CI.

## CLI

```
yaao status [run-id] \
  [--watch]              # live-attach mode
  [--json]               # machine output
  [--task <id>]          # focus on a single task's logs
  [--last]               # most recent run; default if no run-id
```

## Default Output (text)

```
$ yaao status
run a3f1k · plan: my-feature · status: success
duration: 4m 12s · 7/7 tasks · merged: 6 · pr: 1

id            status     agent        duration   files
scaffold      ✔ done     claude-code  0:42       14
api           ✔ done     cursor       1:18       18
ui            ✔ done     api          1:24       11
auth          ✔ done     claude-code  0:55        9
docs          ✔ done     codex        0:30        4
migrations    ✔ done     claude-code  0:21        2
integration   ✔ done     codex        1:41        3 (PR #142)
```

## `--watch`

Re-attaches to an in-flight run by tailing the journal *and* subscribing to the in-process run-bus over the run's IPC socket (`.yaao/runs/<run-id>.sock`). When the run was started by another process, attaches to the socket; if the socket is gone (run finished), falls back to journal replay. Brings up the same TUI as `yaao run` (F11.3).

## `--task <id>`

Prints (or tails with `--watch`) the captured output log for that task: `.yaao/runs/<run-id>/<id>/output.log`.

## `--json`

Emits the `RunSummary` (F3.4) as a single JSON object. Suitable for scripting:

```bash
$ yaao status --json | jq '.tasks | map(select(.status == "failed"))'
```

## `--last`

Convenience: picks the most recent run by start time. With no other flags, prints the summary.

## Acceptance Criteria

- Works on completed runs (journal-only).
- Works on in-flight runs (socket attach).
- `--watch` survives the run finishing — degrades from socket-attach to final-state print.
- `--json` matches the `RunSummary` schema.
