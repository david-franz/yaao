# F4.2 Claude Code Backend

**Phase**: 4 — Agent Backends
**Priority**: Critical
**Dependencies**: F4.1

## Goal

Drive the `claude` CLI in non-interactive mode, stream its output, expose tool/MCP calls.

## Invocation

```
claude --print \
  --output-format stream-json \
  --model <model> \
  --mcp-config <ephemeral-json>      # F7.2 supplies this
  [--skill <name>]*                  # F8 generates skill files
  --append-system-prompt <text>      # F7.3 enforcement directive
```

- Run in the task's worktree (`cwd: opts.cwd`).
- Prompt fed via stdin.
- Output parsed line-by-line as JSON; mapped to `AgentEvent`s:
  - `assistant` blocks → `stdout`.
  - `tool_use` blocks → `tool-use` (carry tool name + input as JSON in `data`).
  - `error` lines → `stderr`.

## Availability Probe

```typescript
async isAvailable(): Promise<AvailabilityReport> {
  const bin = config.agents['claude-code'].bin;       // default 'claude'
  if (!(await which(bin))) return { available: false, reason: 'claude not on PATH' };
  const v = await execa(bin, ['--version']);
  return { available: true, version: parseVersion(v.stdout) };
}
```

## Model Mapping

Accepts: `opus`, `sonnet`, `haiku`, or any explicit model ID (`claude-opus-4-7`, etc). The backend translates short aliases into the most recent model ID for that family at the time of release; explicit IDs pass through unchanged.

## MCP Integration

The MCP config file is generated per-spawn as a tmp file:

```json
{
  "mcpServers": {
    "ctx-sys": {
      "command": "ctx-sys",
      "args": ["serve", "--socket", "<auto-spawn socket>"]
    }
  }
}
```

The path is passed via `--mcp-config`. After the run completes, the file is removed.

## MCP Tool-call Capture

When the MCP server is yaao-managed, yaao tails its log and matches calls to this run/task via a request header. The collected `mcpToolCalls` are returned in `AgentResult` for F7.3 to verify.

## Acceptance Criteria

- A trivial prompt ("write hello.txt with the word hello") produces a file in the worktree and exits 0.
- Tool-use events are surfaced; the count matches the number of `tool_use` blocks observed.
- `--model sonnet` runs against the latest Sonnet model.
- Cancellation kills the child process tree (not just the `claude` process if it spawns subprocesses).
- When `claude` is not installed, `isAvailable()` returns `{ available: false, reason: ... }` and `spawn` raises `AgentUnavailableError`.
