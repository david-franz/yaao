# F12.2 `generate_plan` MCP Tool

**Phase**: 12 — yaao-as-MCP
**Priority**: Medium
**Dependencies**: F12.1, F9.5

## Goal

Expose `yaao plan` as an MCP tool so a parent agent (Claude Desktop, Codex, or yaao's own client) can ask yaao to generate an implementation plan.

## Schema

```json
{
  "name": "generate_plan",
  "description": "Generate an implementation plan for a feature or project.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "description": { "type": "string" },
      "scope":       { "type": "string", "enum": ["feature", "project", "auto"], "default": "auto" },
      "format":      { "type": "string", "enum": ["markdown", "speckit", "both"], "default": "markdown" },
      "out":         { "type": "string" },
      "agent":       { "type": "string" },
      "model":       { "type": "string" }
    },
    "required": ["description"]
  }
}
```

## Output

```json
{
  "ok": true,
  "files": [".yaao/plans/oauth.md"],
  "tasks": 9,
  "agent": "claude-code",
  "ctxSysQueries": 4
}
```

The `content` of the MCP response is the plan body (so a parent agent can stash it in its own context). The structured `result` carries metadata.

## Behavior

Same as `yaao plan` (F9.5) — same skill, same agent resolution, same auto-validation. The difference is that progress is streamed via MCP progress notifications:

- `progress: 'spawning agent'`
- `progress: 'agent running (12s)'`
- `progress: 'parsing output'`
- `progress: 'validated'`

## Cancellation

The MCP `notifications/cancelled` message cancels the running agent (F4.1) and produces an `AgentCancelledError`-shaped MCP error.

## Streaming

While the plan is generated, the MCP server forwards captured tool-use events to the parent as progress updates with structured payload `{ tool: 'context_query', input: {...} }`. This lets a parent agent see what's happening inside yaao.

## Acceptance Criteria

- A simple end-to-end through MCP produces a plan file.
- Progress notifications appear at expected milestones.
- Cancellation cleanly stops the agent and returns the right error.
- The structured result matches the schema in tests.
