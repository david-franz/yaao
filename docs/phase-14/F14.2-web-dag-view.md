# F14.2 Web DAG View (Static)

**Phase**: 14 — Web Viewer
**Priority**: Low
**Dependencies**: F14.1

## Goal

A browser-based static viewer for execution plans. Same data as `yaao view` (F11.2) but with mouse, zoom, and a richer detail pane.

## Stack

- React 18 + TypeScript.
- Graph layout: ELK.js (Sugiyama-style with edge bundling) — handles wider plans than the TUI's hand-rolled layout.
- SVG rendering (no canvas; we want crisp text and easy CSS).
- State: Zustand (small, sufficient).
- Routing: TanStack Router or wouter (no SSR needed).

## Pages

- `/plan/:slug` — render the plan DAG and a side detail pane.

## Layout

- Top bar: plan name, task counts, parallelism profile.
- Left: scrollable DAG canvas.
- Right (resizable): selected task detail — full prompt, agent/model, skills, files, validation, ctx-sys settings.

## DAG Rendering

- Each task is a rectangle with id, title, agent badge, status pill (for runs — see F14.3).
- Edges show dependencies; multi-parent edges merge into a small junction marker.
- Pan/zoom with mouse + trackpad; minimap in a corner for large plans.
- Click selects; double-click focuses (zooms to fit the subgraph rooted at that task).

## Filtering

- Search box: substring match on id/title; matches highlighted, others dimmed.
- Filter chips: `agent: cursor`, `merge: pr`, etc. — derived from the plan.

## Theming

- Light/dark with a CSS-vars theme.
- Color scheme matches the TUI's tokens.

## Accessibility

- Keyboard navigation: arrow keys cycle through tasks; enter opens detail; `/` focuses search.
- ARIA labels on every node.

## Acceptance Criteria

- A 60-task plan renders without overlapping edges.
- Detail pane updates instantly on selection.
- Search highlight is debounced; large plans don't lag.
- Keyboard navigation reaches every task.
