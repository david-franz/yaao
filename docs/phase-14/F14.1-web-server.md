# F14.1 `yaao serve --web` HTTP Server

**Phase**: 14 — Web Viewer
**Priority**: Low
**Dependencies**: F12.1, F3.4

## Goal

A small local HTTP server that hosts the web viewer and exposes the run/plan data the viewer needs. Local-only, no auth by default, no external dependencies beyond `npm install -g yaao`.

## CLI

```
yaao serve --web [--port <n>] [--host 127.0.0.1] [--no-open]
```

- `--port`: defaults to 0 (kernel-assigned), printed on startup.
- `--host`: defaults to `127.0.0.1`. Non-loopback binds require `--token <t>` (passed to clients via the URL fragment).
- `--no-open`: don't auto-launch a browser.

## Stack

- HTTP framework: `hono` (small, fast, ESM, ships well in a CLI).
- Bundled static assets in `dist/web/` produced at build time from `web/` (Phase 14 source).
- Server-Sent Events for live run subscription.

## Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/` | Redirect to `/runs` if any, else `/plan/last`. |
| GET | `/static/*` | Bundled JS/CSS/font assets. |
| GET | `/api/agents` | Output of `yaao agents`. |
| GET | `/api/plans` | List of `.yaao/exec/*.yaml`. |
| GET | `/api/plans/:slug` | Resolved plan + DAG layout. |
| GET | `/api/runs` | List of runs (latest first). |
| GET | `/api/runs/:runId` | `RunSummary`. |
| GET | `/api/runs/:runId/tasks/:id/log?from=<n>` | Log tail since byte offset. |
| GET | `/api/runs/:runId/events` | SSE stream of `RunEvent`s (live for in-flight runs; replay for finished). |
| POST | `/api/runs` | Start a run (`{ plan, maxParallel?, only?, skip? }`). |
| POST | `/api/runs/:runId/cancel` | Cancel a run. |

All endpoints return JSON; errors map yaao error codes to HTTP `4xx`/`5xx`.

## SSE Stream

Events match `RunEvent` (F5.2) JSON-encoded:

```
event: task:active
data: {"taskId":"api","agent":"cursor","branch":"oauth/api"}

event: task:output
data: {"taskId":"api","stream":"stdout","chunk":"..."}
```

## Auth

- Default: bound to `127.0.0.1`, no token. Anyone on the loopback interface can use it (i.e., the user, intended).
- Non-loopback: a per-server-instance random token must be presented as `Authorization: Bearer <token>` (or `?token=<t>` for SSE). The startup banner prints the URL with the token embedded for convenience.

## Lifecycle

- The server holds a single project context (cwd at startup).
- Concurrent runs use the same `.yaao/.lock` semantics as the CLI; `POST /api/runs` queues if a run is in flight.
- `Ctrl-C` shuts down cleanly, cancelling in-flight runs.

## Acceptance Criteria

- `yaao serve --web` starts the server and prints a working URL.
- API endpoints return correct shapes; OpenAPI 3.1 spec emitted at `/api/openapi.json`.
- SSE stream survives browser reconnects.
- Non-loopback bind requires a token.
