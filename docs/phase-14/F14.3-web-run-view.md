# F14.3 Web Live Run View

**Phase**: 14 — Web Viewer
**Priority**: Low
**Dependencies**: F14.1, F14.2

## Goal

The browser equivalent of `yaao run`'s live monitor. The same DAG canvas as F14.2, plus live status overlays, a task-table tab, and a streaming log pane.

## Pages

- `/runs/:runId` — live run view.
- `/runs/:runId/tasks/:id` — focused task with full log scrollback.

## Live Updates

- Subscribes to `GET /api/runs/:runId/events` (SSE).
- Reconnect-on-drop with `Last-Event-ID` for replay since the last received event.
- DAG nodes change color/badge on `task:*` events.
- Task table tab updates in place.

## Log Pane

- Selected task's log tail visible in a fixed pane at the bottom, ANSI-rendered.
- "Follow tail" toggle; turns off on user scroll-up, toggles back when user scrolls to bottom.
- "Open in new tab" link goes to `/runs/:runId/tasks/:id` for full scrollback.

## Controls

- Cancel run button (POSTs to `/api/runs/:runId/cancel`).
- Retry-failed-task action on a task's detail.
- Detach (just close the tab — the server keeps running).

## URL State

- The selected task and tab (graph / table) is encoded in the URL hash so bookmarks and refresh work.

## Acceptance Criteria

- Live view updates within ~1 s of the SSE event firing.
- Reconnection after a 5-second network drop replays missed events without duplicates.
- Cancel button works and is idempotent.
- Browser refresh restores the same visual state.
