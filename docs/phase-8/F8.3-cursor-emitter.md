# F8.3 Cursor Skill Emitter

**Phase**: 8 — Skills System
**Priority**: High
**Dependencies**: F8.1

## Goal

Translate a yaao skill into a Cursor rule at `.cursor/rules/<name>.mdc`.

## Output Layout

```
.cursor/rules/<name>.mdc
```

`.mdc` shape (Cursor's rule format):

```mdc
---
description: <skill.yaml description>
globs: <skill.yaml appliesTo.globs joined by comma>
alwaysApply: false
---

<!-- yaao-managed: <name>@<version> sha=<hash> -->

<rendered prompt.md>
```

## Auto-attach vs Manual

- `alwaysApply: true` if `skill.yaml.trigger.alwaysApply: true`.
- Otherwise `alwaysApply: false` and `globs:` provides the path-pattern auto-attach.

For yaao's own skills (`yaao-planner`, `yaao-converter`), `alwaysApply: false` with `globs:` empty — they're only invoked explicitly via `yaao plan`/`yaao convert`.

## Idempotency

Same managed-marker pattern as F8.2; same hand-edit detection.

## MCP Note

The `.cursor/mcp.json` file is *not* written by this emitter; that's F7.2's job (per-spawn ephemeral overlay). Mixing them was tempting but creates correctness problems when multiple users share `.cursor/mcp.json` for non-yaao purposes.

## Acceptance Criteria

- A skill emits to a valid `.mdc` file readable by Cursor.
- Globs are passed through verbatim from `skill.yaml.appliesTo.globs`.
- Hand-edited rules are detected and not silently overwritten.
- A skill with `appliesTo.agents` excluding `cursor` is not emitted.
