# F8.4 Copilot Skill Emitter

**Phase**: 8 — Skills System
**Priority**: High
**Dependencies**: F8.1

## Goal

Generate the two Copilot artifacts a yaao skill needs: a project-wide instruction snippet, and a per-skill prompt file.

## Outputs

```
.github/
├── copilot-instructions.md       # appended to (managed block)
└── prompts/
    └── <name>.prompt.md          # one per skill
```

## `.github/copilot-instructions.md`

A single managed block per skill is appended:

```markdown
<!-- yaao-managed: yaao-planner@1 -->
## yaao-planner

<short description and trigger guidance — typically a one-line summary plus a "to invoke this skill, see .github/prompts/yaao-planner.prompt.md">
<!-- /yaao-managed: yaao-planner@1 -->
```

The emitter respects existing user content and never deletes anything outside its delimiters. Multiple skill blocks coexist; the file ends up with one block per managed skill.

## `.github/prompts/<name>.prompt.md`

```markdown
---
mode: agent
description: <skill.yaml description>
---

<!-- yaao-managed: <name>@<version> sha=<hash> -->

<rendered prompt.md>
```

`mode: agent` activates Copilot's coding-agent mode for the prompt. The exact frontmatter is whatever the current Copilot CLI accepts; the emitter targets the version range that yaao's F4.4 backend supports.

## Invocation Path

The F4.4 backend points Copilot at `.github/prompts/<name>.prompt.md` via its CLI flags. The instruction file's role is to make the skill discoverable in Copilot's standard UI when the user happens to invoke Copilot directly outside yaao.

## Idempotency

- Managed blocks in `copilot-instructions.md` are keyed by `<name>@<version>` and replaced in place.
- Removing a skill removes its block (via `yaao skills sync --remove`).
- Prompt files use the standard managed-marker hash detection.

## Acceptance Criteria

- Multiple managed blocks coexist without breaking each other.
- User-authored content above and below managed blocks is untouched.
- Removing a skill cleans up both the block and the prompt file.
- Hand-edited prompt files are flagged.
