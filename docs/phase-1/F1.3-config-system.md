# F1.3 Configuration System

**Phase**: 1 — Foundation
**Priority**: Critical
**Dependencies**: F1.1

## Goal

A layered, typed, validated configuration system. Defaults at the bottom; environment-variable expansion at the top; secrets isolated.

## Layers (lowest precedence first)

1. **Built-in defaults** (compiled into yaao).
2. **Global config** — `~/.yaao/config.json`.
3. **Project config** — `<cwd>/.yaao/yaao.config.json`.
4. **Project secrets** — `<cwd>/.yaao/secrets.local.json` (gitignored, secrets only).
5. **Environment variables** — `${ENV_VAR}` substitution applied last.
6. **CLI flags** — override per-command.

## Schema

Authored with Zod, exported as JSON Schema for editor IntelliSense.

```typescript
// src/config/schema.ts
import { z } from 'zod';

export const ConfigSchema = z.object({
  $schema: z.string().optional(),
  version: z.literal(1),
  defaults: z.object({
    agent: z.enum(['claude-code', 'cursor', 'copilot', 'codex', 'api']).default('claude-code'),
    model: z.string().default('opus'),
    'max-parallel': z.number().int().positive().default(4),
    'base-branch': z.string().default('main'),
    'worktree-root': z.string().default('.yaao/worktrees'),
  }).default({}),
  merge: z.object({
    strategy: z.enum(['auto', 'pr', 'manual']).default('auto'),
    'on-conflict': z.enum(['manual', 'agent']).default('manual'),
    'conflict-resolver': z.object({
      agent: z.enum(['claude-code', 'cursor', 'copilot', 'codex', 'api']),
      model: z.string(),
    }).optional(),
  }).default({}),
  agents: z.object({
    'claude-code': z.object({ enabled: z.boolean().default(true), bin: z.string().default('claude') }).default({}),
    cursor:        z.object({ enabled: z.boolean().default(true), bin: z.string().default('cursor-agent') }).default({}),
    copilot:       z.object({ enabled: z.boolean().default(true), bin: z.string().default('gh') }).default({}),
    codex:         z.object({ enabled: z.boolean().default(true), bin: z.string().default('codex') }).default({}),
    api: z.object({
      providers: z.record(z.object({
        'api-key': z.string(),       // env-var ref enforced below
        'base-url': z.string().url().optional(),
      })).default({}),
    }).default({}),
  }).default({}),
  'ctx-sys': z.object({
    enabled: z.boolean().default(false),
    'auto-spawn': z.boolean().default(true),
    'require-query': z.boolean().default(false),
  }).default({}),
  plan: z.object({
    format: z.enum(['markdown', 'speckit', 'both']).default('markdown'),
    speckit: z.boolean().default(false),
  }).default({}),
});

export type YaaoConfig = z.infer<typeof ConfigSchema>;
```

## Loader

```typescript
export async function loadConfig(opts: { cwd: string; env: NodeJS.ProcessEnv }): Promise<YaaoConfig>;
```

Steps:
1. Resolve global path: `~/.yaao/config.json` if it exists.
2. Resolve project path: walk upward from `cwd` looking for `.yaao/yaao.config.json` (stops at FS root or `.git/`).
3. Load `secrets.local.json` next to project config if present.
4. Deep-merge in order: defaults → global → project → secrets.
5. Pass through env-var expander (`${VAR}` → `process.env.VAR`; missing var → typed `MissingEnvError`).
6. Validate with Zod; on error throw typed `ConfigValidationError` with the issue path.

## Secret-in-config Guard

Before validation, the loader scans the merged object (excluding the secrets layer) for any leaf string under `agents.api.providers.*.api-key` that is not `${...}`. If found, refuse to start with a typed `LiteralSecretError` pointing at the offending file.

## Programmatic API

```typescript
export interface ConfigLoader {
  load(opts: { cwd: string; env: NodeJS.ProcessEnv }): Promise<YaaoConfig>;
  paths(cwd: string): { global?: string; project?: string; secrets?: string };
}
```

## Acceptance Criteria

- Empty project (no config files): loads with all defaults.
- Layer precedence works: project value overrides global, secrets adds keys without overwriting non-secret config.
- `${VAR}` expansion works; missing var raises `MissingEnvError` with the var name.
- Literal API key in non-secret config raises `LiteralSecretError` with file + JSON path.
- JSON Schema artifact (`schema/config.schema.json`) is emitted at build time and matches the Zod schema.
