# F1.1 Project Setup & Build Pipeline

**Phase**: 1 — Foundation
**Priority**: Critical
**Dependencies**: None

## Goal

Stand up a TypeScript / Node ≥ 20 / ESM project with a build pipeline, a test harness, and a single-binary CLI artifact.

## Deliverables

- `package.json` with `"type": "module"`, `engines.node: ">=20"`, `bin.yaao: ./dist/bin/yaao.js`.
- `tsconfig.json` with `strict: true`, `module: NodeNext`, `target: ES2022`, `moduleResolution: NodeNext`, `verbatimModuleSyntax: true`.
- `tsup.config.ts` producing two outputs: a CLI bundle (`dist/bin/yaao.js`) with a `#!/usr/bin/env node` shebang, and a library bundle (`dist/index.js` + `dist/index.d.ts`) that exports the public API for programmatic consumers and the upcoming MCP server.
- `vitest.config.ts` with workspace-style projects so phase-grouped tests can run independently.
- ESLint (`@typescript-eslint`) and Prettier with sensible defaults.
- A `.nvmrc` pinned to the latest 20 LTS.

## Scripts

```json
{
  "scripts": {
    "build": "tsup",
    "dev": "tsup --watch",
    "test": "vitest run",
    "test:watch": "vitest",
    "lint": "eslint src tests",
    "format": "prettier --write src tests docs",
    "typecheck": "tsc --noEmit",
    "prepublishOnly": "npm run typecheck && npm run lint && npm run test && npm run build"
  }
}
```

## Public API (initial barrel)

```typescript
// src/index.ts
export { yaao } from './cli/index.js';            // top-level CLI runner
export type { YaaoConfig } from './config/types.js';
export type { ExecutionPlan, Task } from './plan/schema/types.js'; // F2.1
```

The library export exists from day one so internal modules (and Phase 12's MCP server) can import them through the same boundary that external consumers will.

## Acceptance Criteria

- `npm install` from a clean clone succeeds on Node 20 and Node 22.
- `npm run build` produces `dist/bin/yaao.js` and `dist/index.js` with type definitions.
- Running `node dist/bin/yaao.js --version` prints the package version.
- `npm test` executes (zero tests so far is fine; the runner must be wired).
- `npm run typecheck` passes with `strict: true`.
- `npm run lint` passes with no errors on the seed code.

## Tests

- `tests/phase-1/build.test.ts` — runs `tsup` programmatically into a tmp dir; asserts the CLI bundle has a shebang and is executable.
- `tests/phase-1/version.test.ts` — execs `dist/bin/yaao.js --version` and matches `package.json`.
