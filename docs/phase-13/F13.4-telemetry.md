# F13.4 Telemetry (Opt-in)

**Phase**: 13 — Distribution & Polish
**Priority**: Low
**Dependencies**: F1.3

## Goal

Optional, anonymous, opt-in telemetry to inform yaao's roadmap. Strictly no plan content, no diffs, no prompts, no model output.

## Default

**Off**. Users opt in explicitly, either at `yaao init` (with a clear prompt) or by setting `telemetry.enabled: true` in `~/.yaao/config.json`.

## What's Collected (when enabled)

| Event | Fields |
|-------|--------|
| `cli:invocation` | `command` (e.g. `run`, `plan`), `exitCode`, `durationMs`, `yaaoVersion`, `nodeVersion`, `os` |
| `run:summary` | task count, layer count, max-parallel used, agents-used (counts per backend), success/failure, totalDurationMs |
| `agent:availability` | which agents `yaao agents` reports as available (counts only, no system identifiers) |
| `error` | `code` (e.g. `YAAO_PLAN_CYCLE`), no message, no stack |

## What's Never Collected

- Plan files, prompts, agent output.
- Repo paths, file names, branch names, commit messages.
- API keys, env vars, hostnames, usernames, IPs.
- Diff statistics beyond aggregate counts (no per-file info).

## Transport

- HTTPS POST to `https://telemetry.yaao.dev/v1/events`.
- Batched: events buffered locally and sent every 24 h or 100 events, whichever first.
- A persistent random `installationId` (UUID) — never tied to identity.
- Failures are silent and non-blocking.

## Controls

- `yaao telemetry status` — show enable/disable + last batch size + endpoint.
- `yaao telemetry off` — disable.
- `yaao telemetry on` — enable.
- `yaao telemetry purge` — delete the local buffer and `installationId`.
- `YAAO_TELEMETRY=0` — env var override regardless of config.

## Compliance

- Documented on a `/privacy` page on the docs site.
- The collection list is committed in code; a CI test enforces that no event field outside the allow-list is added.

## Acceptance Criteria

- Default-off is verified.
- An off install never connects to the telemetry endpoint (verified by network mock).
- Adding a field outside the allow-list breaks CI.
- `yaao telemetry purge` deletes the local buffer file.
