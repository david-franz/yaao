# F13.3 Docs Site

**Phase**: 13 — Distribution & Polish
**Priority**: Medium
**Dependencies**: F1.1

## Goal

A static docs site at `https://yaao.dev` (or wherever) that hosts the command reference, schema reference, and walkthroughs.

## Stack

- **Astro** (or Docusaurus — pick one early). Single deploy via Cloudflare Pages or Vercel.
- Content lives in `website/content/`.
- Code samples are extracted from real fixtures in `examples/` so they don't drift.

## Information Architecture

```
/                     # landing
  /docs/getting-started
  /docs/concepts/
    plans              # implementation plan format
    execution-plans    # execution plan schema
    worktrees          # how parallel runs work
    skills             # skills system
    ctx-sys            # integration story
  /docs/cli/
    init / plan / convert / validate / view / run / status / merge / clean / agents / skills / doctor / serve
  /docs/recipes/
    feature-from-prompt
    project-bootstrap
    parallel-refactor
    pr-mode
    speckit-workflow
  /reference/
    config-schema      # auto-generated from JSON Schema
    plan-schema        # auto-generated
    error-codes        # generated from src/log/errors.ts
  /changelog
  /community
```

## Content Generation

- **CLI reference**: each command has a TS docstring. A build script (`scripts/gen-cli-docs.mjs`) renders them.
- **Schema reference**: rendered from `schema/*.json` via `json-schema-to-markdown`.
- **Error code catalogue**: walks `src/log/errors.ts` for `YaaoError` subclasses with `code` constants and emits a table.

## Links from CLI

When yaao surfaces an error, the message includes a link like `https://yaao.dev/errors/YAAO_PLAN_CYCLE`. The pages are auto-generated and serve as a Google-able landing for support.

## Acceptance Criteria

- Site builds in CI; broken links fail the build.
- CLI reference is generated, not hand-written (no drift).
- Error codes referenced in source must have a corresponding doc page.

## Tests

- `website/scripts/check-links.mjs` — used in CI.
- `tests/phase-13/docs/error-codes-have-pages.test.ts` — every `YaaoError.code` has a matching markdown file.
- `tests/phase-13/docs/cli-doc-generated.test.ts`
