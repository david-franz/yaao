# F18.1 npm Distribution

**Phase**: 13 — Distribution & Polish
**Priority**: High
**Dependencies**: F1.1

## Goal

Publish `yaao` to npm with a proper bin, types, and a clean install footprint.

## Package Layout

```
yaao/
├── dist/
│   ├── bin/yaao.js                   # CLI entry, has shebang
│   ├── index.js                      # library API
│   ├── index.d.ts
│   └── skills/                       # built-in skill source-of-truth (yaao-planner, yaao-converter)
├── schema/
│   ├── config.schema.json            # JSON Schema for yaao.config.json
│   └── execution-plan.schema.json    # JSON Schema for execution plans
├── package.json
├── README.md
├── LICENSE
└── CHANGELOG.md
```

## `package.json`

```json
{
  "name": "yaao",
  "version": "0.1.0",
  "type": "module",
  "engines": { "node": ">=20" },
  "bin": { "yaao": "./dist/bin/yaao.js" },
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": { "import": "./dist/index.js", "types": "./dist/index.d.ts" },
    "./schema/config":         "./schema/config.schema.json",
    "./schema/execution-plan": "./schema/execution-plan.schema.json"
  },
  "files": ["dist", "schema", "README.md", "LICENSE", "CHANGELOG.md"],
  "scripts": {
    "prepublishOnly": "npm run typecheck && npm run lint && npm run test && npm run build && node scripts/check-clean-publish.mjs"
  }
}
```

## Pre-publish Verification

`scripts/check-clean-publish.mjs`:
- Greps `dist/` for `console.log` (should be zero outside CLI handlers).
- Verifies `dist/bin/yaao.js` is executable and has the shebang.
- Verifies `schema/*.json` matches the in-source Zod schemas (re-emit and diff).
- Refuses to publish from a dirty git tree.

## Versioning

- Semver discipline. Pre-1.0: patch = bug fix, minor = feature, major = breaking.
- Schema changes (`yaao.config.json`, execution plan) require a `version:` bump in the schemas themselves; yaao reads any older version compatibly within the same major.

## Tags

- `latest` — most recent stable.
- `next` — pre-release builds; `npm install -g yaao@next`.

## Install Smoke Test

A post-publish CI job installs `yaao` globally on a clean Node 20 image and runs:
```
yaao --version
yaao agents
yaao init && yaao validate .yaao/exec/sample.yaml
```

## Acceptance Criteria

- `npm install -g yaao` produces a working `yaao` on PATH.
- The package weighs less than 5 MB (excluding any optional dev artifacts).
- Schemas are accessible via the `exports` map.
- A dirty git tree blocks publish.
